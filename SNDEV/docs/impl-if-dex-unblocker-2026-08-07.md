BLOCKER / deviation discovered:

  is wrong for this build, so the canonical 577-entry table cannot yet be built from `species.dat`.

  save has encountered. To get the full canonical 577 table: provide a **decrypted** `species.dat` (plain
  marshal) or `PBS/pokemon.txt` and re-run the generator (`genorder gen-dat`).
